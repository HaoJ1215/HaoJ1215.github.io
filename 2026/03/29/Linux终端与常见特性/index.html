Linux终端与常见特性

一、目录结构

/
├── bin/ # 基本命令二进制文件
├── boot/ # 启动加载文件
├── dev/ # 设备文件
├── etc/ # 系统配置文件
├── home/ # 用户主目录
├── lib/ # 系统库文件
├── media/ # 可移动媒体挂载点
├── mnt/ # 临时挂载点
├── opt/ # 可选应用软件包
├── proc/ # 进程和内核信息
├── root/ # root用户主目录
├── run/ # 运行时数据
├── sbin/ # 系统管理命令
├── srv/ # 服务数据
├── sys/ # 系统设备信息
├── tmp/ # 临时文件
├── usr/ # 用户程序和数据
└── var/ # 可变数据文件

二、文件类型

目录文件d、链接文件l、管道文件p、设备文件c、b、套接字文件s、普通文件

三、权限

chmod r(4), w(2), x(1), -(0)

四、终端常用命令

  1. cp：拷贝
  2. rm：删除
  3. mv：移动/重命名
  4. vim：文本编辑
  5. cat：查看/合并
  6. more：分页查看
  7. tail：查看尾部
  8. less：高级分页查看
  9. head：查看头部
  10. find：文件查找
  11. grep：文本搜索
  12. tar：归档压缩
  13. ps：进程查看
  14. kill：杀死进程
  15. &：后台运行

五、程序编译链接

apt、install、gcc/g++/vim/make

xx.c->xx 预处理、编译、汇编、链接

六、调试：GDB

常用命令

  1. l：显示代码
  2. b：下断点
  3. info break：查看断点信息
  4. r：运行程序
  5. n：单步执行
  6. p：打印
  7. s：进入函数
  8. finish：跳出函数
  9. q：退出调试

七、库文件

定义：预先编译好的方法的集合

libxx.a：静态库—用到的方法会拷贝到可执行程序中

libxx.so：共享库—不会拷贝用到的共享库，运行程序时动态链接

八、进程与信号

fork()

**功能：**创建当前进程的一个子进程副本

特点：

  1. 返回值：父进程返回子进程PID；子进程返回0；失败返回-1

  2. 写时拷贝：子进程不立即复制父进程的内存空间；共享同一物理内存页；当任一进程尝试写入时，才复制该内存页

  3. 子进程继承父进程的代码段、数据段、堆栈、打开的文件描述符、信号处理函数、当前工作目录等

exec()

**功能：**替换当前进程的内存映像，加载并执行新程序

特点：

  1. 不创建新进程，替换当前进程

  2. 成功时不返回（原程序被覆盖）

  3. 失败时返回 -1

  4. 通常与fork()配合使用

kill()

**功能：**向指定进程发送信号

参数说明：

  1. pid:（>0）发送给指定PID的进程；（==0）发送给同进程组的所有进程；（==-1）发送给有权限的所有进程；（<-1）发送给进程组ID为|PID|的所有进程
  2. sig：信号编号

常用信号

信号 值 默认动作 说明
SIGHUP 1 Term 终端挂起
SIGINT 2 Term 中断（Ctrl+C）
SIGQUIT 3 Core 退出（Ctrl+\）
SIGKILL 9 Term 强制终止（不可捕获）
SIGTERM 15 Term 优雅终止
SIGSTOP 17,19,23 Stop 暂停进程（不可捕获）
SIGCONT 18,19,25 Cont 继续执行

signal()

**功能：**设置信号处理函数

处理方式

  1. 自定义函数：signal(SIGINT, my_handler)
  2. 忽略信号：signal(SIGINT, SIG_IGN)
  3. 默认处理：signal(SIGINT, SIG_DFL)

写时拷贝

原理

  1. fork()时：父子进程共享同一物理内存页
  2. 设置页表：所有共享也标记为只读
  3. 写入时：触发页错误异常->内核复制该页->修改页表->恢复写入操作

有点

  1. 高效：避免不必要的内存复制
  2. 快速：fork()几乎立即返回
  3. 节省内存：只复制实际修改的页

库函数vs系统调用

特性 库函数（Library Function） 系统调用（System Call）
定义 标准C库提供的函数 操作系统内核提供的接口
位置 用户空间 内核空间
调用方式 普通函数调用 通过软中断（如int 0x80）
执行速度 较快（无上下文切换） 较慢（需要上下文切换）
可移植性 高（跨平台） 低（操作系统相关）
示例 printf(), malloc() read(), write(), fork()
错误处理 设置errno 返回错误码

常见对应关系

库函数 底层系统调用 说明
fopen() open() 打开文件
fread()/fwrite() read()/write() 文件读写
malloc()/free() brk()/sbrk() 内存分配
printf() write() 格式化输出
getpid() 直接系统调用 获取进程ID
