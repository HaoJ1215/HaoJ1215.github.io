c语言概念+数据类型+运算符

Author: JiangHao Date: June 14, 2025  11:07:50 Category: learning records skills

c语言简单概念

  1. C语言特点: 结构化\高效\底层控制能力强

  2. c语言开发环境:

    1. 编辑器: VS Code\Dev-C++
    2. 编译器: GCC(gcc hello.c -o hello)

  3. 程序结构:

数据类型

基本数据类型

类型 说明 内存 示例
int 整型 4字节 int a = 10;
float 单精度浮点型 4字节 float b = 3.14f;
char 字符型 1字节 char c = 'A';
double 双精度浮点型 8字节 double d = 3.14159;

运算符

算术运算符

运算符 名称 示例 功能说明
+ 加法 a + b 两数相加
- 减法 a - b 两数相减
* 乘法 a * b 两数相乘
/ 除法 a / b 两数相除（整数/浮点数结果不同）
% 取模（取余） a % b 返回两数相除的余数（仅限整数）
++ 自增 a++ / ++a 变量值+1（前/后自增）
– 自减 a-- / --a 变量值-1（前/后自减）

关系运算符

运算符 名称 示例 功能说明
== 等于 a == b 判断 a 和 b 是否相等
!= 不等于 a != b 判断 a 和 b 是否不相等
> 大于 a > b 判断 a 是否大于 b
< 小于 a < b 判断 a 是否小于 b
>= 大于或等于 a >= b 判断 a 是否大于或等于 b
<= 小于或等于 a <= b 判断 a 是否小于或等于 b

逻辑运算符

运算符 名称 示例 功能说明
&& 逻辑与（AND） a && b 当 a 和 b 都为真时返回 1（否则返回 0）
|| 逻辑或（OR） a || b 当 a 或 b 至少一个为真时返回 1
! 逻辑非（NOT） !a 如果 a 为假（0），则返回 1（否则返回 0）

位运算符

运算符 名称 示例 功能说明 运算规则
& 按位与（AND） a & b 逐位进行与运算 两位均为1时结果为1，否则0
| 按位或（OR） a | b 逐位进行或运算 两位至少一个为1时结果为1，否则0
^ 按位异或（XOR） a ^ b 逐位进行异或运算 两位不同时结果为1，否则0
~ 按位取反（NOT） ~a 对a的每一位取反 0变1，1变0（单目运算）
<< 左移 a << n 将a的所有位左移n位 低位补0，高位丢弃
>> 右移 a >> n 将a的所有位右移n位 高位补符号位（算术右移）或无符号补0（逻辑右移）
